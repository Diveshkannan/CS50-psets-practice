
Personal Workspace: CS50x Week 8 Homepage


Overview

Personal Workspace is a front-end web development project created for CS50x Week 8 (Problem Set 8: Homepage). It is designed to help users explore potential career paths, maintain personal details, and connect their workspace with useful development profiles. The project focuses on providing a clean, accessible interface for choosing a career direction and displaying related information using multi-page navigation.

Features

• Home Page: Introduces the Personal Workspace platform and project goals.
• About Us: Explains the project's purpose, vision, and core concepts.
• Login Page: Collects user details and links to development profiles.
• Choose Path: Allows users to select a career path related to computer science or engineering.
• Profile Page: Displays saved user information and provides workspace-related options.
• Password Page: Provides a basic client-side password verification interface.
• Error Page: Displays a message when the allowed number of login attempts is exceeded.
• Navigation: Enforces a consistent navigation bar enabling users to move between the different pages.
• Data Storage: Uses browser localStorage and sessionStorage to store and manage information.
• URL Display: Supports displaying user-provided profile and development-related URLs.

Technologies Used

• HTML5 — Structures the web pages.
• CSS3 — Styles the interface, layouts, buttons, gradients, and interactive elements.
• JavaScript — Handles navigation, input validation, browser storage, and page interactions.
• Bootstrap 5 — Provides access to Bootstrap's front-end styling and responsive components.
