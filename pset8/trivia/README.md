# Trivia!

A small interactive trivia web application built while learning **JavaScript, DOM manipulation, event handling, and interactive web development**.

This project was an important step for me because I didn't simply copy a complete implementation. **The idea and the logic I wanted to build were mine**, while I used Google and AI to look up JavaScript syntax and understand how to implement specific things when I didn't know the syntax yet.

## What the Project Does

The trivia application contains two sections:

### Part 1 — Multiple Choice

Users can answer multiple-choice questions by clicking the available options.

The program:

- Detects which option was clicked.
- Checks the selected answer.
- Displays `Correct` or `Incorrect`.
- Changes the button appearance based on the result.
- Prevents unnecessary rechecking after a question has already been answered.

### Part 2 — Free Response

The user can type an answer into an input field and submit it.

The program:

- Reads the user's input.
- Checks whether an answer was entered.
- Converts the input to uppercase for comparison.
- Displays whether the answer is correct or incorrect.
- Changes the input appearance based on the result.
- Prevents further editing after a correct answer.

### DOM Manipulation

I learned how JavaScript can find HTML elements and modify them dynamically.

For example, the program can:

```text
User clicks button
       ↓
JavaScript detects the event
       ↓
Answer is checked
       ↓
Result text changes
       ↓
Element styling changes
```

### Event Listeners

One of the important ideas I learned was attaching the same kind of behaviour to multiple elements.

Instead of manually writing separate event listeners for every button, I used a shared class and processed the matching elements with `querySelectorAll()` and `forEach()`.

This made me start thinking about **how to design the interaction**, rather than only thinking about individual lines of syntax.
