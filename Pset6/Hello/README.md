# Hello, Name

## Description

A simple Python program that asks the user for their name and prints a personalized greeting.

## Code

```python
name = input("What's your name? ")

print(f"Hello, {name}")
```

## Concepts Learned

* `input()` — gets text from the user.
* Variables — stores the entered name in `name`.
* f-strings — inserts the value of `name` directly into the greeting.
* `print()` — displays the final message.

## Example

```text
What's your name? Divesh
Hello, Divesh
```

## Purpose

This small program demonstrates basic **user input, variables, string formatting, and output in Python**.
